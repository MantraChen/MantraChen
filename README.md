> I study how systems behave under concurrency, resource constraints, and adversarial conditions.

## Research & Engineering

**Systems & Concurrency**  
Concurrent data structures, memory ordering, and safe memory reclamation. Exploring how cache behavior and memory layout shape practical performance.

**Kernel Security**  
Kernel attack surfaces, object lifecycles, and isolation boundaries. Understanding exploitation mechanisms and strengthening systems through sandboxing and integrity monitoring.

**Adversarial Systems & Anti-Cheat**  
Runtime integrity, behavioral detection, and hypervisor-assisted introspection. Examining the trade-offs between detection accuracy, performance, and resistance to evasion.

**Algorithms & Data Structures**  
Graph algorithms, combinatorial optimization, and cache-conscious design. Connecting algorithmic reasoning with the constraints of real systems.
